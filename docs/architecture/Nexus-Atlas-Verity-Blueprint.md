# Nexus Atlas × Verity Blueprint v0.1

This blueprint keeps the hackathon implementation inside the permanent Nexus Atlas architecture.

```text
Personal Intelligence Infrastructure
  → Nexus Atlas
  → Innovation Territory
  → Verity Re-entry
```

Verity is the public Hero Scenario. Nexus Self-Re-entry remains the internal technical validation fixture.

## Scenario source

The complete scenario source is stored in:

```text
continuity/scenarios/verity-reentry/
```

Generate the standard fixture with:

```bash
npm run build:verity-scenario
```

This creates:

```text
continuity/scenarios/verity-reentry.json
```

The generator validates the schema version, project identity, expected finding counts, and JSON integrity before writing the fixture.

## Product guardrail

The competition deepens one complete vertical slice, but Atlas Desk, Atlas Map, Territory Workspace, Context Inspector, Agent Workspace, and Action Tray remain permanent Nexus product layers. No Verity-specific object becomes a core Context Fabric primitive.
